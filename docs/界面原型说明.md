# 界面原型说明（UI Prototype）

> 本文档基于 `iframe/` 目录源码（ai-chat.html / ai-chat.css / ai-chat.js / editor-drawer.js / graph-view.js）整理，
> 以「界面原型 + 交互态」视角描述 AI巧绘插件的可视化结构，作为《系统设计说明》《AI执行框架设计说明》的界面补充。
> 不含代码片段，仅描述界面「长什么样、有哪些状态、点哪里会发生什么」。

## 一、整体界面地图

## 二、对话主界面（ai-chat.html）

### 2.1 标题栏

- 左侧显示标题「原理图设计 AI巧绘」，采用蓝紫渐变背景（`#667eea → #764ba2`）。
- 右侧按钮组（白字半透明按钮）：
  - **自动执行**：复选框，默认未勾选；未勾选时写操作代码块仅展示「确认执行」按钮、需用户手动点击才会运行，勾选后代码块进入即延迟约 2 秒自动落地（等效于自动点击确认执行）。
  - **配置**：打开 ARK API 配置对话框。
  - **数据**：打开数据管理抽屉。
  - **清空**：清空当前对话（保留欢迎语）。处于"待确认执行"状态（存在未确认的代码块）时点击清空，会弹出友好提示「请先点击停止结束当前操作，再清空会话」，避免误以为按钮无响应。
- 当后端返回鉴权类错误时，「配置」按钮会变红并脉冲闪烁，引导用户去修正 Key/Model。

### 2.2 消息区（messages-container）

- 背景浅灰，纵向滚动，含自定义滚动条。
- **欢迎语**：居中展示，列出 AI巧绘可做的事（解答问题、元件选型、方案分析、布局优化）。
- **消息气泡**：
  - 用户消息：右侧对齐，蓝紫渐变气泡，右下角小圆角。
  - 助手消息：左侧对齐，白底灰边气泡，左下角小圆角，淡入动画。
- **加载动画**：三点跳动（`.loading-dot`）。
- **代码块**：出现于助手消息中，含深色代码区（`#282c34` 等宽字体，确认前可**直接编辑**）+ 底部操作栏（「回退原始」灰色按钮 / 「确认执行」橙色按钮）；编辑态内描边黄色高亮提示已修改，未改动时「回退原始」禁用；下方可展开执行结果（`code-result`）。
- **错误提示**：红色边框气泡，由 `handleAIError` 渲染为**三段式结构化引导**——「❌ 标题」+「原因说明」+「💡 可操作建议」。标题按错误类型区分：鉴权失败 / 请求过于频繁 / 网络异常 / 请求超时 / 参数错误 / 工具执行失败 / 响应解析失败 / 操作失败。原因说明**直接采用后台透传的真实错误文本（唯一、明确）**，不再叠加假设性文案。
  - 鉴权失败（AUTH）的建议**依据真实原因动态生成，绝不臆测**：若真实原因属"额度/套餐/配额"类（如"您当前没有可用额度的Token"），则提示去领取/购买套餐，**不提示配置 API Key**；若确为"API Key/模型缺失或无效"，才提示点击「配置」填写；无法判定时给中性提示。配置按钮变红脉冲（`config-btn-alert`）**仅**在确为 Key/模型配置问题时触发，额度类问题不误高亮。
  - 用户主动点「停止」造成的中断**不显示错误气泡**，仅状态栏提示「已停止」。

### 2.3 输入区（input-container）

- 多行文本框（`message-input`，Enter 发送），聚焦时边框变蓝紫。
- 右侧两个按钮：
  - **停止**（红橙渐变，仅在 SENDING / EXECUTING 状态显示）：真正中断当前生成——底层网络请求被 abort，而非仅界面停住；同时取消「自动执行」等待中的延时。
  - **发送**（蓝紫渐变，IDLE / STOPPED 可用）：提交消息。
- 底部状态栏（`status-text`）：显示运行态提示，支持普通/错误（红）/成功（绿）三色。

### 2.4 对话状态机（UI_STATE）与控件可用性

| 状态 | 输入框/发送 | 停止 | 清空 | 自动执行 | 配置 |
| --- | --- | --- | --- | --- | --- |
| `IDLE` 空闲 | 可用 | 隐藏 | 可用 | 可用 | 可用 |
| `SENDING` 发送中 | 禁用 | 显示 | 禁用 | 可用 | 可用 |
| `STOPPED` 停止中 | 禁用 | 隐藏 | 禁用 | 禁用(取消选中) | 可用 |
| `EXECUTING` 执行中 | 禁用 | 显示 | 禁用 | 可用 | 可用 |

## 三、配置对话框（config-dialog）

- 全屏遮罩 + 居中卡片（最大宽 500px），头部蓝紫渐变标题「ARK API 配置」。
- 引导文案：提供火山引擎官网链接与「私服登录」链接（指向 `https://113.46.209.138/login`）。
- 配置项：
  - **使用私服**：复选框。勾选后隐藏「API Model」输入，切换为走私服通道。
  - **API Key**：文本输入。
  - **API Model**：文本输入（使用私服时隐藏）。
- 底部：`[保存]`（蓝紫主按钮）/`[取消]`。保存后即时生效并在会话间持久化（`localStorage`）。

## 四、数据管理抽屉（editor-drawer.js）

### 4.1 容器与遮罩

- 全屏定位层（`z-index:1100`），半透明遮罩（点击关闭），右侧滑出面板占屏宽 90%。
- 通过主界面右上角「数据」按钮或图谱联动打开；关闭按钮（×）或点遮罩关闭。

### 4.2 头部（dm-header）

- 左侧标题「数据管理」+ **状态徽标**：
  - 已激活：`已激活 · 数据库 v{版本}`（绿底）。
  - 未激活：`未导入 · 原始JS(只读预览)`（灰底）。
- 右侧全局操作按钮（并排，**不分区**，白字；仅保留高频必要项）：
  - `导入`：点击后弹询问框选择来源，详见 4.2.1。
  - `导出`：点击后输入一次版本号，产出单个 JSON 文件，详见 4.2.2。
  - `删除数据库`：红底危险按钮，删除库并回退原始 JS（即恢复默认）；删除即视为恢复默认，故不再单独提供「恢复全部默认」按钮。
  - `×`：关闭。

#### 4.2.1 导入询问框（两项来源）

点击「导入」后弹出**自定义询问框**（居中卡片 + 半透明遮罩，非浏览器原生 `confirm`），含三个并列的整行按钮：

- **从源码导入**：**不弹文件选择框**。源码文件已在页面加载时由宿主执行，其数据即存在于运行时内存的 `window.promptList` / `window.edaApi` / `window.mcpProtocol` / `window.curatedTools` 中，点击后直接读取这些内存常量写入数据库并激活。这是**首次使用的激活起点**（此时本地尚无任何导出文件）。
- **从本地文件导入**：弹出文件选择，仅接受 `psa-export.v*.json` 文件，导入本地数据。
- **取消**：关闭询问框，不执行任何导入（点击遮罩关闭同理）。

> 原「导入默认1.0」内存快照入口已移除，统一由「从源码导入」作为真正的激活起点；原「导入文件」与「导入默认」的冗余并排被合并为单一「导入」按钮 + 询问框。

#### 4.2.2 导出（单文件）

点击「导出」→ 输入一次版本号 → 下载单个 `psa-export.v{版本}.json`：提示词 / 业务数据，工具按 `source`（jdb / mcp / custom）分组，重新导入可正确还原所有分类。

> 函数实现源码以 `impl_code` 字段内嵌于该 JSON 中，导入时自动重建为可调用函数，因此单文件即可完整还原，无需附带独立 JS 文件；与「从本地文件导入」仅接受 `.json` 形成对称闭环。原「导出JSON」「导出默认JS」两个拆分按钮已合并。

### 4.3 六个分栏（dm-tabs）

标签带条目计数（图谱例外），自左向右按下列顺序排列，点击切换并重置到首页：

1. **图谱**：位于最左侧，关系图谱可视化，标签不带计数；激活时隐藏左侧列表与分隔条，编辑区占满为画布。
2. **提示词(n)**：提示词列表，支持新增/删除自定义提示词。**抽屉打开时默认停留在此分栏**。
3. **精选工具(n)**：精选自定义工具 + MCP 元工具合并。
4. **EDA函数(n)**：原生 API 描述浏览与编辑。
5. **资源(n)**：资源查看与编辑（显示态 @引用高亮 + 编辑态表单保存，与提示词分栏对称，支持单条恢复出厂默认）。
6. **日志(n)**：调用快照；**未激活时整栏隐藏**，若正停留其上自动回退提示词栏。

### 4.4 工具栏（dm-toolbar）

- 搜索框：按 name/uri/description 模糊匹配（忽略大小写），输入即过滤并回首页；**日志与图谱分栏隐藏**（图谱用自带搜索框）。
- `新增` 按钮：仅提示词/精选工具分栏且已激活时显示。
- `清空日志` 按钮：仅日志分栏显示。

### 4.5 列表 + 编辑双栏（dm-body）

- 左列表 `dm-list-wrap`（默认宽 38%，最小 260px）：
  - 条目显示：名称（等宽字体）+ 描述（超长省略）+ 标记——`●` 红点表示已修改，`已禁用` 灰标表示工具禁用。
  - 选中条目左侧蓝竖条高亮（`.dm-item-active`）。
  - 底部分页器：`上一页`/`下一页` + `当前页 / 总页 · 共 N 条`，每页 50 条。
- **可拖拽分隔条 dm-splitter**（5px，hover/拖拽变蓝）：实时调节左右宽度；比例不持久化，重开恢复默认。
- 右编辑区 `dm-edit`：
  - 未选条目显示居中占位「请选择左侧条目进行查看 / 编辑」。
  - 未激活时顶部显示只读横幅「当前为只读预览(原始JS数据)，请先『导入 → 从源码导入』激活数据库后再编辑」，所有输入禁用。

### 4.6 编辑面板（显示态 / 编辑态切换，二选一不并存）

- 面板以 `editMode` 控制两种互斥状态：**显示态**（默认，只读高亮预览）与**编辑态**（可编辑表单）。
  - 切换选中条目、跳转引用、保存成功均自动回到显示态。
  - 未激活（只读预览）时强制显示态，且「编辑」按钮禁用。
- **提示词**：
  - 显示态：描述 + 内容（纯文本或 messages JSON）以 `dm-code-view` 只读高亮展示（含 `@引用` 高亮）；按钮：编辑 / 恢复此条默认 / 删除（带引用保护）。
  - 编辑态：描述输入 + 内容编辑（单条纯文本消息直接编辑 `content.text`，否则编辑完整 messages JSON）；按钮：保存 / 取消。
- **工具（EDA函数/精选工具/元工具）**：
  - 显示态：描述 + 参数模式 + 函数实现（仅 mcp/custom 有，原生 API 无此栏）以只读高亮展示（含 `@引用` 高亮）+ 启用状态；引用关系提示区（调用了谁 / 被谁引用）；按钮：编辑 / 恢复此条默认 / 删除（仅用户自建或已修改的 custom 工具）。
  - 编辑态：描述 + 参数模式(JSON，保存强校验) + 函数实现 + 启用开关；引用关系提示区；按钮：保存 / 取消 / 「AI 格式化并补全(代码+描述)」（仅含函数体工具，生成中按钮置灰并显示「AI 处理中…」）。
- **资源**：只读展示描述与内容（`dm-code-view`）。
- 设计约束：**编辑态与显示态不并存**——编辑态只显示可编辑表单与保存/取消，不在下方重复展示 `@引用` 只读预览；`@引用` 高亮预览仅存在于显示态。

### 4.7 `@引用` 标记交互（dm-ref）

- 编辑区正文中的 `@name` 渲染为蓝色高亮片段。
- 函数实现（impl_code）中的「真实调用」同样渲染为蓝色高亮片段，且具备与 `@name` 完全相同的单击信息卡 / 双击跳转能力：`window.curatedTools.<name>(...)`、`window.mcpProtocol.<name>(...)` 高亮方法名并跳转到对应工具；`eda.<完整路径>` 高亮并跳转到对应 EDA 原生 API（jdb）。
  - **单击**：弹出信息卡（类型 / 描述 / 启用态；目标不存在则标红「未找到该引用」；工具禁用时黄字警示）。
  - **双击**：跳转到对应条目（联动切换分栏并选中）。
- 上述 `@引用` 高亮出现在显示态的只读预览区（提示词内容、工具函数实现、参数模式等），单击/双击行为同上。
- 文本送入模型前统一还原为裸 `name`，模型所见与标记化前一致。

### 4.8 日志分栏（logs）

- 左列表为会话列表（按创建时间倒序），右编辑区展示选中会话的逐轮快照：
  - 每轮整体包裹在 `<details>`（**默认折叠**），点击轮次标题可整轮展开/折叠；时间标题按**本地真实系统时间**显示（时区本地化，无 UTC 偏移）。
  - 轮次标题栏右侧提供**「复制」按钮**：点击将该轮完整请求/响应 JSON 写入剪贴板（按钮阻止事件冒泡，不会误触发折叠）。
  - 请求快照 / 响应快照：各自以标签直接呈现，**不再整体折叠**；JSON 内容按 `{ }` `[ ]` 真实层级递归拆为可折叠单元，每个对象/数组**默认展开**，仅在左括号前显示折叠箭头（▶/▼），不显示键名与数量等统计文字。字符串值内的 `@引用` 保持高亮与跳转能力。
  - JSON 解析失败时降级为纯文本展示，避免整段日志无法查看。
- 底部「清空日志」仅删日志两表，不动业务数据。

## 五、关系图谱视图（graph-view.js）

> 仅在「图谱」分栏激活时渲染，复用编辑区主区作为全屏画布。数据来自 `dataStore.buildGraph()`，基于 D3 力导向布局。

### 5.1 画布布局（dm-graph-canvas）

- 纯色干净背景（`#fbfcfe`，无点阵网格），承载 SVG 力导向图，避免缩放后节点与背景灰点重叠导致辨识困难。
- 顶部工具栏（左上）：独立搜索框（`搜索节点(name/描述/内容)…`）+ `适应画布` + `重置布局`。
- 图例（右上，可点击）：五类节点色板——提示词(蓝 `#4e79f7`)、精选工具(绿 `#2ecc71`)、MCP元工具(橙 `#f39c12`)、EDA原生API(灰 `#95a5a6`)、资源(紫 `#9b59b6`)；点击切换显隐，`off` 态半透明加删除线。
- 默认隐藏 EDA 原生 API（千级节点默认折叠）与资源资料（海量节点默认折叠）以保证性能，需手动在图例开启；被提示词 @uri 引用时资源节点随连线出现。

### 5.2 节点与连线视觉

- **节点**：圆形，按出入度缩放半径（4~14px）；按类型着色。
- **连线（5 类，按类型着色，强弱以粗细区分）**：
  - `prompt_ref` 提示词引用提示词（蓝，强引用）。
  - `prompt_tool` 提示词引用函数/资源（青绿；目标是资源时连线落地到紫色资源节点）。
  - `tool_call` 函数调用函数（绿）。
  - `describes` 描述-实现配对（灰，不生成连线仅保留图例配色）。
  - `native_fallback` 降级调用原生API（橙，标记非常规路径）。
  - `example_call` 调用范例（浅灰，弱引用）。
  - 强弱（strength）以线条粗细区分；逐类型箭头 marker；自环边（source===target）双保险过滤不渲染。
- **悬停 tooltip**（深色浮卡）：画布默认不显示节点名称（保持清爽），悬浮节点弹出丰富信息——名称（带类型色块，与画布配色一致）/ 类型·分类 / 标识(id) / 被引用·引用他人次数 / 描述（多行限高滚动）；连线显示 引用类型 / 起止 / 强弱。

### 5.3 交互

- **拖拽节点**：自由布局；`Shift` 拖拽或右键「钉住」固定位置，再次右键「解钉」释放。
- **缩放平移**：滚轮/拖拽画布空白（zoom 0.1~8x）。
- **选中**：单击节点**品红（`#ff1493`）描边**高亮，**跨重绘与切分栏持久保留**（刻意避开节点填充色，避免与 mcp 节点橙色混淆）。
- **搜索高亮**：输入关键词命中节点及其完整引用链路（BFS）点亮、无关元素淡出；**当仅命中唯一节点时自动选中（品红描边）并居中放大，免去手动定位**；`Enter` 在多个命中间循环居中。
- **双击节点**：联动打开数据管理抽屉并定位编辑。
- **右键菜单**（三类，按下触发防冒泡）：
  - 节点：编辑 / 复制 name / 钉住或解钉 / 以此为中心聚焦 / 删除（带引用保护）。
  - 连线：查看引用上下文 / 解除引用并定位编辑 / 强弱切换（仅提示，实际由语法自动判定）。
  - 空白：新建提示词 / 新建函数（精选工具）/ 适应画布 / 重置布局 / 导出图谱 PNG。
- **导出 PNG**：序列化当前 SVG 并下载 `relation-graph.png`。
- **浮层渲染机制**：悬停 tooltip 与右键菜单均为「挂在 `.dm-panel`（`position:absolute` 且 `overflow` 默认可见）的 `position:absolute` 浮层」，坐标由鼠标视口坐标换算为相对 `.dm-panel` 左上角的偏移。**严禁改回 `position:fixed` + `document.body`**——在 VSCode 扩展的 webview 内，fixed 浮层会被宿主层级裁剪/遮挡（DOM 已渲染但视觉不可见）。

### 5.4 离线降级

- 若 D3 未加载（`window.d3` 缺失），图谱分栏降级为**文字版引用列表**（节点按类型列举 + 引用关系列表），功能不丢失。

## 七、关键交互链路（界面视角）

1. **激活**：数据 → 导入 → 从源码导入 → 徽标变绿 → 日志栏出现 → 编辑可用。
2. **写操作确认**：对话中 AI 返回代码块 → 界面展示「确认执行」→ 点击后画布落地（或勾选自动执行后约 2 秒自动落地）→ 结果回填气泡。代码块在确认前支持**实时编辑**：用户可直接修改代码文本，改动后操作栏内描边黄色高亮提示，「回退原始」按钮可用以一键还原 AI 原始代码；确认执行时若内容与原始代码不同，将按编辑后的代码动态执行，否则沿用原生路径。
3. **引用跳转**：编辑区 `@引用` 双击 → 抽屉切分栏并选中目标 → 可查看/编辑其引用上下文。
4. **图谱联动**：图谱双击节点/连线右键「编辑」→ 抽屉打开并定位 → 修改保存后即时生效，图谱刷新保留选中态。
5. **日志回溯**：数据 → 日志栏 → 选会话 → 展开轮次 → 点「复制」按钮复制该轮 JSON。
