# AI巧绘 — 原理图设计助手

> 详细开发文档请访问：[https://prodocs.lceda.cn/cn/api/guide/](https://prodocs.lceda.cn/cn/api/guide/)

## v1.0.8 新特性

本次更新聚焦「连接模式扩展、模型透明化、故障可上报、用量可观测」，核心亮点：

- **🔀 第三种连接模式**：配置弹框在原有「私服」「ARK 官网」基础上，新增「自定义模型」模式，用户可自填 API Key / Base URL / Model（如 deepseek、glm 等主流模型兼容端点），开箱即用。
- **🏷️ 当前模型信息展示**：对话界面状态栏新增「模型」标识，私服模式下由服务端返回实际服务模型，非私服模式展示本地配置模型，让用户明确感知当前用的哪个模型。
- **📣 故障一键上报**：对话出现不可预知报错时，错误气泡末尾出现「上报此问题」链接，自动收集错误堆栈并经客服通道提交管理员；未登录私服用户点击时引导先注册登录。
- **📊 Token 流量分析**：每次对话自动采集 Token 消耗并上报，管理员页新增「Token 流量」Tab，以日/周/月柱状图展示插件流量趋势，便于容量与成本分析。
- **🎁 领取信息透明**：用户套餐块展示已领取的模型类型与剩余数量。

> 更多历史变更见文末「更新日志」与 `CHANGELOG.md`。


## 功能概述

AI巧绘 是一款专为原理图设计人员开发的智能工具，具备以下核心功能：

1. **AI 对话**：支持自然语言问答与上下文管理，快速解答原理图设计相关问题
2. **工具调用**：AI 可以调用 EDA API 读取原理图信息，如查询选中元件、读取原理图结构等
3. **代码执行**：集成火山引擎 ARK API，为设计场景生成代码块，AI 生成的代码块支持直接编辑后**经用户确认执行**
4. **知识图谱**：D3 力导向图可视化展示提示词、工具与资源的引用网络，支持搜索居中与节点高亮
5. **抽屉面板**：右侧六栏抽屉（图谱/提示词/精选工具/EDA函数/资源/日志），一键切换浏览
6. **安全确认**：代码执行前需用户确认，可开启自动执行开关实现自动执行

### 私服模式说明

本扩展支持连接**外部私服后端**进行对话（由私服转发至 ARK ）。需要说明：

- 本扩展侧提供一个「私服登录」跳转入口，用户在私服页面完成登录后领取 Token 即可在配置中使用；

## 核心模块与协作

AI巧绘并非一个单一功能的聊天框，而是由几块各司其职的界面与底层数据层协同工作的工具集。理解它们的分工，能帮助你更高效地使用。

| 模块 | 它是什么 | 对你有什么用 |
| --- | --- | --- |
| **对话主界面** | 日常的问答与操作入口 | 用自然语言描述需求，AI 在此返回可在画布上执行的代码块，并支持编辑确认后执行 |
| **数据管理抽屉**（右侧六栏） | 存放驱动 AI 的"燃料"：提示词与工具 | 查看 / 编辑提示词（AI 的指令框架）与工具（AI 能调用的能力清单），让 AI 更智能，更贴合你的设计习惯 |
| **关系图谱** | 把抽屉里的数据画成引用网络 | 改动前先看清"改一个工具会影响哪些提示词"，避免误删导致 AI 失能 |

**它们如何配合（一句话主线）**：

> 你在**对话主界面**描述需求 → AI 依靠**数据管理抽屉**里的提示词与工具来理解和执行 → **关系图谱**帮你理清这些提示词与工具之间的引用关系。

典型工作流示例：

1. 初次使用：直接对话即可，AI 基于内置的默认提示词与工具工作。
2. 想要对 AI 的工作流程进行自定义编辑：打开「数据」抽屉，先「导入 → 从源码导入」激活数据库，随后编辑提示词、增删工具。
3. 改动前不放心：切到「图谱」分栏，看清待改条目的引用关系，再决定是否编辑或删除。


## 快速上手

只需三步即可开始使用：

1. **安装扩展**：在嘉立创 EDA 扩展管理器搜索「AI巧绘」安装。
   ![导入AI巧绘扩展](images/import.gif)
2. **配置 AI 通道**：打开对话界面 → 点击右上角「配置」→ 填入火山引擎 ARK 的 API Key（或勾选「使用私服」并先去私服页面登录领取 Token）。
   ![使用前配置api key](images/apikey.gif)
3. **开始对话**：在输入框描述需求（如"查询选中元件的详细信息"），对 AI 返回的代码块点击「确认执行」即可在画布上落地。

> 进阶玩法（编辑提示词 / 工具、查看引用图谱）见下方「数据管理抽屉」与「关系图谱」章节，需先「导入 → 从源码导入」激活本地数据库。

### 1. 导入扩展

2. 高级 → 扩展管理器

2. 高级 → 扩展管理器 → 导入
3. 选择扩展包文件完成安装

1. 在扩展管理器中启用扩展，并确保已开启 **外部交互**
2. 打开 AI巧绘对话界面（通过菜单 `AI巧绘` → `原理图设计助手`）

4. 在配置对话框中填写以下信息：
   - **API Key**：火山引擎 ARK API Key
   - **API Model**：API Model（使用私服时不需要填写）
   - **使用私服**：可选择使用私服模式，使用私服时只需填写 API Key

> 注意：
  需要配置自己的 AI KEY。ARK API 凭证获取方式：前往 [火山引擎官网](https://www.volcengine.com/) 注册并获取 API Key 和 Model 信息。
  或者点击配置对话框中的"私服登录"链接领取 token 后使用。

![使用前配置api key](images/apikey.gif)

### 3. 使用入口

- Home / Sch / PCB 菜单：`AI巧绘` → `原理图设计助手` 打开对话
- 关于：`AI巧绘` → `About...`

## 功能介绍

### AI 对话

在输入框中输入原理图设计相关问题，AI 会根据问题给出专业回答。支持自然语言问答与上下文管理，能够理解设计意图并提供针对性建议。

AI 可以调用 EDA API 工具来读取原理图信息，例如：
- 查询选中元件的详细信息（参数、封装等）
- 读取原理图中的所有元件列表
- 获取元件的引脚信息
- 分析原理图结构和连接关系

### 元件信息查询

在原理图中选中元件后，在对话界面输入相关问题（如"查询这个元件的详细信息"），AI 会调用 EDA API 读取选中元件的信息并返回详细结果。

![使用场景1 获取鼠标选中的元件的信息](images/scenario1.gif)

### 复合任务处理

AI巧绘支持处理复杂的复合任务，可以一次性完成多个操作。例如：
- 查询多个元件信息并进行分析
- 批量读取原理图数据并进行处理
- 执行多个工具调用完成复杂的设计任务

通过自然语言描述任务需求，AI 会理解任务意图，自动调用多个 EDA API 工具，按步骤完成复合任务。

![使用场景2 复合任务](images/scenario2.gif)

### 代码自动执行

AI 可以根据对话内容生成可在画布上执行的代码块，用于读取或修改原理图。代码执行机制：

- **确认执行**：默认情况下，AI 生成的代码块会显示在对话界面，需点击「确认执行」按钮才会真正运行，避免误改设计文件
- **自动执行**：开启对话界面右上角的「自动执行」开关后，代码块会在短暂延迟后自动执行，适合批量重复操作
- **可编辑**：执行前可直接修改代码块中的参数或逻辑，按你调整后的内容运行

支持的操作包括：
- 批量修改元件参数
- 放置元件到原理图
- 创建导线连接
- 查询和分析原理图结构

### 数据管理抽屉（右侧六栏）

点击对话界面右上角「数据」按钮可打开右侧抽屉。抽屉默认以**只读预览**方式展示内置数据；点击「导入 → 从源码导入」激活本地数据库后，即可编辑。六个分栏各解决一类问题：

- **图谱**：用一张关系网络图，呈现提示词、工具之间的引用关系。*何时用*：改动或删除某条数据前，先来这里看清"会影响哪些条目"，避免误删导致 AI 失能。
- **提示词**：AI 的指令框架（系统提示词、各角色框架提示词等）。*何时用*：想调整 AI 的回答风格、专业度或约束规则（如元件选型规范）时，在此查看或编辑。
- **精选工具**：AI 可直接调用的自定义工具与封装能力。*何时用*：想扩充 AI 能做的事（如新增一种批量操作）时，在此查看或新增。
- **EDA函数**：嘉立创 EDA 原生 API 的完整列表。*何时用*：查阅某个原生接口的能力与参数，作为编写工具的参考。
- **资源**：由数据文件导入维护的 EDA 开发资料条目，支持查看、编辑与单条恢复出厂默认。*何时用*：查阅或维护嘉立创原理图 EDA 相关资料素材时，在此浏览或编辑。
- **日志**：每次对话的请求与响应完整记录。*何时用*：复盘某次对话 AI 到底调了什么、为什么出错时，在此按会话回溯。

**这个抽屉能帮你做什么**：你可以修改提示词、新增「精选工具」来优化插件在本地的表现（例如补充某种元件选型规范、封装一项批量操作）。当你打磨出好用的数据后，可将其导出为 JSON，通过 GitHub 提交 Pull Request；经管理员审批合并后，这些数据就能提供给更多用户使用。如果你有功能需求或改进想法，也可以通过下方的「客服」通道直接联系管理员，我们很乐意听取你的建议。

![抽屉面板](images/drawer.gif)

### 关系图谱

图谱面板以力导向图形式呈现提示词、工具之间的引用关系网络：

- 节点越大表示被引用的次数越多；连线越粗表示调用关系越强（弱引用以虚线区分）
- 单击节点可高亮其关联链路，双击节点可跳转到对应条目编辑界面
- 搜索时唯一匹配节点自动居中定位
- 悬浮节点可查看详细信息

![知识图谱](images/graph.gif)

### 代码块可编辑

AI 生成的代码块支持直接编辑，修改后仍可执行：

- 点击代码块进入编辑模式，修改参数或逻辑
- 修改后点击「确认执行」按钮，即按修改后的代码运行（未勾选「自动执行」时不会自动执行）
- 编辑与只读模式互斥，避免误操作

### 数据导入导出

数据面板提供本地数据管理能力：

- **导入数据**：弹出询问框，可选择「从源码导入」（加载内置工具与提示词数据，也是首次激活数据库的入口）或「从本地文件导入」（从外部 JSON 文件导入自定义工具或提示词）
- **删除数据库**：独立的入口，删除本地 IndexedDB 数据库并回退到原始 JS 内置默认数据（不参与上方导入流程），用于放弃全部用户修改、恢复出厂状态
- **导出**：将当前数据导出为单个 JSON 文件，可分享给其他人使用
- **存储说明**：所有数据保存在浏览器本地的 IndexedDB 数据库中（底层由 AlaSQL 提供 SQL 能力），关闭插件后持久保留，无需联网

![数据导入导出](images/import-data.gif)
